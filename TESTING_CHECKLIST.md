# MindEase - Testing Checklist

Use this checklist to verify all functionality works correctly.

## ✅ Pre-Testing Setup

- [ ] MongoDB is running
- [ ] `.env` file is configured
- [ ] Dependencies installed (`npm install`)
- [ ] Server starts without errors (`npm start`)
- [ ] Browser opens to `http://localhost:5000`

---

## 🔐 Authentication Tests

### Registration
- [ ] Navigate to http://localhost:5000 (should redirect to login)
- [ ] Click "Sign up" link
- [ ] Try registering with invalid email → Should show error
- [ ] Try registering with weak password (no uppercase) → Should show error
- [ ] Try registering with weak password (no number) → Should show error
- [ ] Try registering with passwords that don't match → Should show error
- [ ] Try registering without agreeing to terms → Should show error
- [ ] Register with valid data → Should succeed and redirect to dashboard
- [ ] Try registering again with same email → Should show "email already exists" error

### Login
- [ ] Go back to login page
- [ ] Try logging in with wrong password → Should show error
- [ ] Try logging in with non-existent email → Should show error
- [ ] Log in with correct credentials → Should redirect to dashboard
- [ ] Check that welcome message shows your name

### Session Persistence
- [ ] Close browser
- [ ] Open browser and go to http://localhost:5000/dashboard.html
- [ ] Should still be logged in (session persists)

### Logout
- [ ] Click "Logout" button in sidebar
- [ ] Should redirect to landing page or login
- [ ] Try accessing http://localhost:5000/dashboard.html
- [ ] Should redirect to login (protected route)

## 📝 Assessment Tests

### Starting Assessment
- [ ] Log in to dashboard
- [ ] Click "Start Assessment" or navigate to Assessment page
- [ ] Read introduction screen
- [ ] Verify response scale is displayed (0-4)
- [ ] Click "Begin Assessment"

### Question Navigation
- [ ] Verify Question 1 appears
- [ ] Verify progress bar shows 4% (1/25)
- [ ] Verify section name shows "Attention and Concentration"
- [ ] Try clicking "Next" without selecting answer → Should show error
- [ ] Select an answer
- [ ] Click "Next" → Should go to Question 2
- [ ] Verify progress bar updates to 8% (2/25)
- [ ] Click "Previous" → Should return to Question 1
- [ ] Verify your previous answer is still selected
- [ ] Verify "Previous" button is disabled on Question 1

### Draft Saving
- [ ] Answer first 5 questions
- [ ] Click "Save Progress"
- [ ] Should see "Progress saved" message
- [ ] Log out
- [ ] Log back in
- [ ] Go to Assessment page
- [ ] Should see prompt to continue saved assessment
- [ ] Click "Yes" → Should resume at Question 6 with previous answers saved

### Completing Assessment
- [ ] Answer all 25 questions
- [ ] On Question 25, "Next" button should say "Review Answers"
- [ ] Click "Review Answers"
- [ ] Verify all sections are shown with your answers
- [ ] Verify you can see all 25 responses
- [ ] Click "Back to Questions" → Should return to Question 25
- [ ] Click "Review Answers" again
- [ ] Click "Submit Assessment"
- [ ] Verify confirmation dialog appears
- [ ] Click "Yes" → Should redirect to results page

### Protected Routes
- [ ] Log out

  - [ ] http://localhost:5000/dashboard.html → Should redirect to login
  - [ ] http://localhost:5000/assessment.html → Should redirect to login
  - [ ] http://localhost:5000/wellness-plan.html → Should redirect to login
  - [ ] http://localhost:5000/profile.html → Should redirect to login

### Password Security
- [ ] Passwords are never visible in:
  - [ ] Network requests (check DevTools Network tab)
  - [ ] Local storage
  - [ ] Session storage
  - [ ] Console logs

### Session Security
- [ ] Sessions use HTTP-only cookies
- [ ] Check DevTools → Application → Cookies
- [ ] Verify `connect.sid` cookie exists
- [ ] Verify it has `HttpOnly` flag (in production)
